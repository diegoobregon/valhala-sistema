# Sistema Web B2B - VALHALA S.A.C.

Control de Flota y Logística de Alquiler de Maquinaria de Línea Amarilla

## Estructura del repositorio
- **valhala-backend/** : API REST en Java (Spring Boot 3, Spring Security JWT, JPA)
- **valhala-frontend/** : SPA en Angular 17 + PWA Offline-First
- **valhala-db/** : Script SQL PostgreSQL (16 tablas + particiones IoT) y diagramas
